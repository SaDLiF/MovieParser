# MovieParser

Каталог фильмов и сериалов (TMDB, CUB), онлайн-просмотр через балансеры Lampac и AniLibria,
плейлисты и собственный телеканал с телепрограммой для локальной сети.

## Установка и обновление

Обновления ставятся автоматически: `Updater.exe` берёт последний [релиз](https://github.com/SaDLiF/MovieParser/releases/latest),
сравнивает файлы с `manifest.json` и скачивает только изменившиеся архивы.

| Файл | Что внутри |
|---|---|
| `MovieParser-app.zip` | приложение |
| `MovieParser-vlc.zip` | VLC (качается только при изменениях) |
| `MovieParser-ffmpeg.zip` | ffmpeg для телеканала и длительности серий |
| `manifest.json` | список файлов с размером и SHA-256 |
| `version.txt` | номер последней версии |
